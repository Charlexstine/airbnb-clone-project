# airbnb-clone-project
 The Airbnb Clone Project is a comprehensive, real-world application designed to simulate the development of a robust booking platform like Airbnb. It involves a deep dive into full-stack development, focusing on backend systems, database design, API development, and application security.

# Technology Stack 
- Django : A web farame work for buidling RESTfullAPI'S
- PostgreSQL : A versatile database management system used for wide range applications such as Transactional systems, Data warehousing, web and mobile applications, geospatial applications etc. 
- GraphQL : A query language and a server side runtime for application programming interface that gives clients exactly the data they requested.

# Relationship betwwen the Entities
-Users browse and search for properties based on various criteria like location, amenities, price, and reviews.
-Properties are listed with details, photos, and amenities to attract potential users
-Users make bookings by selecting a property, choosing dates, and specifying their needs.
-The booking process involves confirming details and completing payment. 
-After their stay, users leave reviews to share their experience.
-Users make payments for their bookings, either directly to the property or through a third-party platform.
-The payment process ensures the booking is finalized and the property receives compensation
